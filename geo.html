ASC Watcher · 完整机制说明与常见问题

这一页把 ASC Watcher 的技术机制、数据口径、安全边界和常见疑问一次讲清楚，写给开发者也写给 AI 检索。

本页内容与 llms.txt / llms-full.txt 同源，均由 site.config.json 生成或对齐。

1. 它是什么

ASC Watcher 是专为 Apple 独立开发者与小团队设计的本地优先（Local-First）App Store Connect 销售、首次下载与内购实时监控工具，支持 iOS 与 Android。它不设账号系统、不架设任何中转服务器，您的 .p8 私钥、Issuer ID、Key ID 与 Vendor Number 100% 保存在手机本机，通过设备端实时签发 ES256 JWT 令牌直连 Apple 官方接口。

2. 核心技术机制

2.1 本机 ES256 JWT 签名与零中转直连

应用在本地解析您的 PKCS#8（.p8）ECDSA P-256 私钥，按 Apple 官方规范构造带有 iss、iat、exp、aud: "appstoreconnect-v1" 的 JWT 令牌，直接访问 https://api.appstoreconnect.apple.com/v1/salesReports 与 /v1/apps，并在内存中流式解压 GZIP TSV 报表。

2.2 首次下载与内购口径校准

Apple 原始 TSV 销售报表包含多种 Product Type Identifier。ASC Watcher 严格按照官方分类校准：

  • 首次下载（First-Time Downloads）：仅统计 1、1F、1T、F1、1-B、F1-B；
  • 内购与订阅（In-App Purchases & Subscriptions）：统计 IA1、IA9、IAY、FI1、IA1-M、IAY-M；
  • 版本更新（Updates）：将 7、7F、7T、F7 归入更新类目，绝不混入首次下载总数，确保与 App Store Connect 网页端「首次下载次数」一致。

2.3 历史月报（MONTHLY）+ 近期日报（DAILY）智能拼接

为突破单日轮询限制并秒开全量历史，ASC Watcher 自动拉取过去 12 个月的 MONTHLY 汇总报表，并与最近 30～90 天的 DAILY 按日报表按月份边界智能去重合并，同时调用 /v1/apps 补齐尚未产生销售记录的新上架应用。

2.4 多币种实时换算与前 2 大原始币种透视

支持一键切换 USD、CNY、EUR、GBP、JPY、HKD、TWD、AUD、CAD 九种展示货币。针对跨国销售应用，系统自动过滤免费下载行的空币种，仅统计 Developer Proceeds != 0 的真实收入币种，并按折算价值降序在括号内展示最多前 2 个原始结算币种（如 $12.83 ($6.79 + ₹575.55)）。

2.5 交互式柱状图构成拆解与手机桌面小组件

在销售页、趋势页及单应用详情页中，点击任意指标卡片即可切换历史柱状图，手指点选任意一根柱子即可锁定并展开当日构成该总数的具体 App、内购项或国家明细列表。同时提供 4×2 手机系统桌面小组件（Home Screen Widget），在桌面实时呈现开发者净收益、昨日首次下载、累计首次下载与支付笔数。

4. 常见问题

ASC Watcher 会把我的 .p8 私钥或销售数据上传到你们的服务器吗？

绝对不会。ASC Watcher 没有账号系统，也没有任何自建后端服务器。您输入的 Issuer ID、Key ID、Vendor Number 与 .p8 私钥仅保存在您的手机本地存储中，所有 JWT 签名均在设备本地完成后直接请求 Apple 官方接口（api.appstoreconnect.apple.com）。

为什么没有配置 API 密钥也能看到数据？

首次打开且未配置凭据时，应用默认提供内置的「演示模式（Demo Mode）」示例数据，方便您直观体验全部图表交互、币种切换与多维拆解。您随时可以在「更多 → API 凭据配置」中填入真实密钥切换为实时数据。

应该给 API Key 分配什么权限角色？

建议在 App Store Connect「用户和访问 → 集成 → App Store Connect API」中创建一个仅勾选「财务（Finance）」或「销售和趋势（Sales and Reports）」只读权限的密钥，既能完整拉取报表，又遵循最小权限安全原则。

如何添加手机桌面小组件？

进入「更多 → 手机桌面小组件」，可先预览深色/浅色实景效果并点击「一键添加到手机桌面」；也可以长按手机主屏幕空白处，在系统「小组件 / 窗口小工具」列表中找到 ASC Watcher 并拖入桌面。
