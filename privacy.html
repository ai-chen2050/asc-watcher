隐私政策

生效日期：2026-10-30 · 适用于 ASC Watcher iOS 与 Android 版

ASC Watcher 是一款纯本地运行的 App Store Connect 销售与下载分析工具。我们没有账号系统，也没有任何自建或中转服务器。 下面按「收集什么、存在哪、有哪些直连请求、你怎么删」四件事把话说清楚。

1. 我们收集什么

我们不收集任何个人信息或财务数据。应用无需注册登录，不采集设备标识、位置或通讯录， 不含任何第三方统计分析或广告 SDK，也不上报崩溃或使用日志。您在应用内配置的 App Store Connect API 凭据（Issuer ID、Key ID、Vendor Number 及 .p8 私钥）以及拉取到的应用列表、首次下载量、内购与开发者净收益报表，100% 仅保存在您的设备本地，我们无法看到或访问。

2. 数据存储位置

所有配置与报表缓存均保存在您设备的应用私有沙盒存储（SharedPreferences / 本地缓存）中；手机桌面小组件（Home Screen Widget）展示的汇总数字同样存储在系统本地应用组/共享偏好中，不会离开您的设备。

3. 网络请求与第三方服务

本应用不经过任何开发者服务器，仅在以下情形由您的设备直接发起 HTTPS 请求：

  • Apple App Store Connect 官方接口（api.appstoreconnect.apple.com）：使用您在设备本地通过 ES256 签名的 JWT 令牌，直接向 Apple 拉取您名下应用列表与销售/下载 TSV 报表；
  • Apple iTunes Lookup 接口（itunes.apple.com）：根据应用的 Apple ID 或 Bundle ID 查询公开的 App Store 应用图标高清地址；
  • 公开汇率参考接口：拉取主流货币（USD、CNY、EUR、GBP、JPY 等）的公开基准汇率用于本地金额折算展示，不包含任何个人或账号标识。

4. 可选的自带 Key 扩展能力

若您在支持自定义密钥扩展的版本中主动配置外部服务 API Key，所有请求均直接从您的设备发往对应服务商，不经过我们的任何服务器，且未配置时不发起任何此类连接。

5. 权限用途

权限用途是否必需
网络访问（INTERNET）在设备端直连 Apple 官方 App Store Connect 接口拉取报表、获取应用图标及最新公开汇率必需（演示模式除外）
文件读取（系统文件选择器）在凭据设置页由您主动选择本地 .p8 私钥文件导入文本，应用不会后台扫描您的相册或文件目录可选
桌面小组件（AppWidget）在手机主屏幕展示净收益、昨日首次下载与累计销量速览卡片可选

6. 数据清除与断开连接

您随时可以在应用内「更多 → 清理报表本地缓存」一键清空已缓存的销售报表，或在「更多 → 断开此账号连接」彻底擦除保存在本机的 Issuer ID、Key ID、Vendor Number 及 .p8 私钥。卸载本应用会连同设备上的全部本地数据一并清除。

7. 政策变更

本政策如有变更，会更新本页并修改上方生效日期；涉及数据处理方式的重大变化会在应用内提示。
