为什么做 ASC Watcher：零服务器直连与下载口径校准

独立开发者每天最关心的就是旗下几款 App 昨天进了多少新用户、产生了多少笔内购。我们做了一款无需把 .p8 私钥交给任何第三方云端、100% 在手机本地签名直连 Apple 的随身看板。

结论先说

ASC Watcher 没有账号系统，也没有中转服务器。你的 .p8 私钥、Issuer ID、Key ID 和 Vendor Number 只存在你自己的手机里，每次下拉刷新都在本地完成 ES256 JWT 签名，直接请求 api.appstoreconnect.apple.com。

解决了什么痛点

  1. 私钥安全：很多第三方统计平台要求上传 .p8 密钥到他们的服务器定时拉取。其实手机端完全有能力自己完成 ECDSA P-256 签名与 GZIP TSV 流式解压。
  2. 首次下载与更新不混算：原始 TSV 报表里 Product Type Identifier = 7 / 7F 是老用户自动更新，如果直接把所有正数 Units 相加，算出来的下载量会比 App Store Connect 网页端虚高几倍。ASC Watcher 严格只把 1 / 1F / 1T / F1 计入首次下载，IA1 / IA9 / IAY 计入内购与订阅。
  3. 多币种折算与原始入账兼顾：支持 9 种目标货币实时换算，同时在括号里保留折算价值最高的前 2 个原始结算币种（如 ($6.79 + ₹575.55)），既看清总额又不丢细节。
  4. 柱状图点选拆解 + 手机桌面小组件：点选柱状图任意一天即可列出当天是由哪几个 App、哪几个国家或内购商品构成的；加上 4×2 手机桌面小组件，解锁手机就能一眼看到最新收益与昨日下载。
