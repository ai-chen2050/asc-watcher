本页是华为应用市场渠道版：该版本没有任何联网分析功能，没有任何数据会离开你的设备。

下载或使用 ASC Watcher 即表示您同意本协议。协议中的「我们」指本应用开发者，「您」指使用本应用的开发者或团队成员。

1. 许可范围

我们授予您一份个人的、不可转让的、非独占的许可，在您拥有或控制的设备上安装和使用本应用，用于查看与分析您享有合法授权的 App Store Connect 销售与下载报表。您不得反向工程、篡改或将本应用用于任何非法用途。

2. API 凭据与本地数据安全

本应用采用纯本地架构，不设账号系统，也不托管您的任何密钥。您在应用内填入的 Issuer ID、Key ID、Vendor Number 与 .p8 私钥仅保存在您的设备本地。请妥善保管您的手机设备，并在 App Store Connect 后台为该 API Key 仅授予只读的「销售和趋势（Sales and Reports）」或「财务（Finance）」最小权限。数据处理详情请参阅隐私政策。

4. 报表数据与汇率折算免责声明

本应用按「现状」提供，作为开发者的辅助统计看板：

  • 应用内的首次下载、更新次数、内购笔数及开发者净收益（Developer Proceeds）均直接解析自 Apple App Store Connect 官方返回的每日（DAILY）与月度（MONTHLY）TSV 报表；由于 Apple 后台存在时区切日（太平洋时间/UTC）、滚动窗口重算及月度财务结算延迟，最终结算金额请以 Apple 官方月度财务报告（Financial Reports）及银行打款为准；
